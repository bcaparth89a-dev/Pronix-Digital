# Pronix Digital

Production-ready MERN project architecture with React, Vite, Tailwind CSS, ShadCN UI, Express, MongoDB, JWT auth foundations, Cloudinary, Nodemailer, and shared application infrastructure.

## Structure

- `client`: React/Vite frontend architecture.
- `server`: Node/Express backend architecture.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Copy environment files:
   ```bash
   cp client/.env.example client/.env
   cp server/.env.example server/.env
   ```
3. Run development servers:
   ```bash
   npm run dev
   ```
